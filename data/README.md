# Datos

El dataset no se incluye en el repositorio para evitar duplicar archivos de terceros.

Fuente: https://www.kaggle.com/datasets/amandam1/healthy-vs-diseased-leaf-image-dataset

Descarga el conjunto y utiliza la carpeta `A Database of Leaf Images/Lemon (P10)`, que debe contener las subcarpetas `diseased/` y `healthy/`.

No subas datos al repositorio hasta comprobar las condiciones de redistribución de Kaggle. La ruta local de los datos debe configurarse en el notebook.
