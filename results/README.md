# Resultados

Los CSV incluidos resumen las métricas obtenidas durante el experimento en Google Colab. La validación fue de 47 imágenes y no se utilizó un conjunto de prueba independiente.

Las latencias y tamaños dependen del entorno y de los archivos descargados. Los tamaños incluyen posibles archivos auxiliares y no representan necesariamente el tamaño final de una aplicación desplegada.
